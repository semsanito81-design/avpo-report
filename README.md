# Отчет АВПО (KSC -> Excel)

Скрипт для автоматизации формирования еженедельных отчетов по антивирусной защите (АВПО) на основе CSV-выгрузок из Kaspersky Security Center (KSC).

## 🚀 Возможности
- Загрузка данных из нескольких CSV-файлов KSC.
- Сохранение истории проверок (снимков) в локальную базу SQLite.
- Формирование единого Excel-отчета с разделением по месяцам (каждый месяц — отдельный лист).
- Автоматическая группировка по неделям (четвергам).
- Выделение серверов в конец таблицы (на основе `servers.txt`).
- Сохранение ручных правок («Отчет об устранении») между формированиями отчетов.

## 🛠 Установка и запуск

### Требования
- Python 3.10+
- Библиотеки: `pandas`, `openpyxl`

### Windows
1. Скачайте репозиторий.
2. Запустите `run.bat` (сам создаст виртуальное окружение и установит зависимости).
3. В открывшемся окне нажмите «Загрузить папку data/» и «Сформировать отчет».

### Linux / RHEL / Fedora
1. Скачайте репозиторий.
2. Выполните `chmod +x run.sh`.
3. Запустите `./run.sh` (скрипт проверит и при необходимости установит зависимости через `dnf`).

## 📂 Как это работает
1. Выгрузите отчеты из KSC в формате CSV.
2. Положите их в папку `data/`.
3. В программе выберите дату проверки (четверг) и нажмите «Загрузить папку data/».
4. Нажмите «Сформировать отчет» — готовый файл появится в папке `out/`.

## 📝 Настройка
- **`servers.txt`** — список серверов. Хосты из этого файла будут отсортированы в конец отчета.
- **Ручные правки** — если вы отредактировали Excel-файл вручную, сохраните его и нажмите «Импортировать правки из Excel». Программа запомнит их для будущих отчетов.
